RESPONSIBLE DISCLOSURE

Security Policy

Luminary Technicals welcomes responsible security research that helps protect Luminary AI Engine and its users. Please report suspected vulnerabilities privately and give maintainers enough information to reproduce and assess the issue.

Project security policy · Updated 12 November 2026

How to report a vulnerability

Email luminaryaiengine@luminarytechnicals.dpdns.org with the subject [Security] Luminary AI Engine vulnerability report.

Include a description, affected component, safe steps to reproduce, impact assessment and a suggested mitigation when available. Do not include passwords, API keys, user conversations or unrelated personal data.

Do not open a public GitHub issue for an unpatched security vulnerability. Coordinate disclosure with the maintainers before sharing technical details publicly.

Scope

  • Luminary AI Engine frontend and browser application.
  • Optional API services and their routes, authentication and authorization.
  • Rate limiting, data-handling and research-dataset controls.
  • Deployment configuration, Docker images and security headers.

Third-party services and dependencies are not directly maintained by this project. Report vulnerabilities to their respective maintainers as well, and provide relevant context to this project when our integration is affected.

Safe testing

Test only systems you own or have explicit permission to assess. Avoid service disruption, denial-of-service testing, accessing other users’ data, persistence, destructive actions or social engineering. Stop testing and report the issue when sensitive data or production impact is encountered.

Response expectations

The repository’s security notes describe an intended acknowledgement within 48 hours, an initial assessment within 7 days and a fix or mitigation target within 30 days for critical issues. These are project targets, not a guarantee of resolution. Complex issues, upstream dependencies and circumstances outside the project’s control may affect timelines.

Technical security notes

Read the repository security notes for implementation details and supported-version information. Review the Privacy Policy for data-handling disclosures.

For general product issues, use the Contact & Support page.
