Domain Policy & Provider Disclosure

This page explains the domain arrangement for luminaryaiengine.dpdns.org and distinguishes the website publisher from the domain namespace provider, DNS configuration, hosting/deployment and source-code repository.

This is a publisher-authored disclosure about the domain arrangement used by the Luminary AI Engine website at luminaryaiengine.dpdns.org. It is not a licence, certificate, endorsement, registration confirmation or official statement issued by DigitalPlat Domains, DPDNS or any related provider entity.

2. Domain namespace and registration context

The site uses a hostname under the dpdns.org namespace. DigitalPlat Domains lists the dpdns.org namespace among its public domain namespaces and provides registration workflows subject to its current terms and availability.

A domain name is an internet address. Registration or delegation of a hostname does not establish ownership of the parent namespace, a business partnership or common management with the namespace provider. Current registration status, account-level details, nameservers and renewal conditions should be checked in the relevant provider dashboard and official registration records.

4. Domain, DNS, hosting and publishing are separate roles

  • Website publisher: Luminary Technicals publishes and maintains the Luminary AI Engine website and its project content.
  • Domain namespace/registration service: DigitalPlat Domains provides registration workflows for public namespaces, including *.dpdns.org, subject to its own policies and availability.
  • DNS configuration: DNS records and nameserver delegation determine where the hostname resolves. These settings are separate from the website's content and source code.
  • Hosting and deployment: The web application is deployed separately from the domain registration. The repository contains Netlify edge configuration; the hosting/deployment provider and runtime configuration remain separate technical roles.
  • Source-code repository: Project source is maintained in the Luminary AI Engine GitHub repository ↗.

Use of a domain namespace does not imply that the namespace provider wrote, reviews, hosts, certifies, sponsors or endorses the website content.
