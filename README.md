# 🧠 Luminary AI LLM Engine

### **Liberated Intelligence. Multi-Model Power. Privacy-First Research.**

![Luminary AI Logo](LuminaryEngine/public/logo.png)

Luminary AI is a high-performance, open-source AI engine designed for researchers, developers, and AI enthusiasts. It provides a unified interface to access over 55+ frontier models with advanced steering capabilities, professional red-teaming tools, and zero-data-retention privacy.

---

## 🚀 Key Features

- **🌐 55+ LLM Models**: Access Claude, GPT, Llama, Gemini, and more via a single interface.
- **🔥 ULTRAPLINIAN Execution**: Parallel multi-model racing for comparative analysis.
- **🐍 Parseltongue Red-Teaming**: Advanced character-level perturbation for AI safety research.
- **⚡ AutoTune Sampling**: Context-adaptive sampling parameters for optimal response quality.
- **🛡️ Secure & Private**: Client-side API key storage and Zero Data Retention (ZDR) architecture.
- **📄 Research-Ready**: Includes a full whitepaper and extensive developer documentation.

---

## 🛠️ Tech Stack

- **Frontend**: Next.js & TypeScript
- **Styling**: Vanilla CSS with futuristic glassmorphic design
- **State Management**: Zustand
- **Animations**: Framer Motion
- **Hosting**: Cloudflare Pages / Vercel

---

## 🏁 Getting Started

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/luminarytechnicals/luminaryaiengine.git
    ```
2.  **Launch the Engine**:
    Open `index.html` in your browser or navigate to [luminaryai.tech](https://luminaryaiengine.netlify.app).
3.  **Configure API**:
    Bring your own OpenRouter API key for full model access. No account required.
