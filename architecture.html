Luminary AI Engine architecture

The system coordinates multiple AI models to generate, critique, compare and refine prompt candidates from a user requirement. Model inference is delegated to third-party model providers through OpenRouter.

Browser application

The standalone application runs in the browser, builds conversation history, stores chat state locally and sends chat-completion requests to OpenRouter. The user supplies the OpenRouter API key. The app does not provide its own foundation model.

ULTRAPLINIAN multi-model prompt council

ULTRAPLINIAN selects a configurable subset of the model roster and sends requests concurrently. The standalone source defines five tiers: Fast (10 models), Standard (24), Smart (38), Power (49) and Ultra (55). Candidate responses are scored by internal quality, fulfilment, filteredness and speed heuristics. An early result may stop the race; otherwise a model-based judge may compare shortlisted candidates.

AutoTune

AutoTune detects query context and computes sampling parameters such as temperature, top-p, top-k and repetition/frequency/presence penalties. Provider support for individual sampling fields may vary.

Evaluation limitations

Scores are heuristic estimates. The scorer does not independently verify claims against primary sources. A high score is not a probability of truth or a guarantee of correctness.

Optional API server

The repository includes an Express API with OpenAI-compatible chat-completions routes, ULTRAPLINIAN and CONSORTIUM endpoints, authentication, operational metadata and an opt-in research-dataset pathway. This service is separate from the static browser frontend and must be deployed independently.
