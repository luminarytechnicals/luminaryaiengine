Luminary AI Engine privacy and data handling

Luminary AI Engine has separate browser, model-provider and optional API-server data paths. No-Log Mode is enabled by default in the standalone browser application.

Browser conversations and API key

The standalone application stores chat conversations and the user's OpenRouter key in browser storage. It does not provide account-based cloud synchronization. Clearing browser storage may permanently remove local conversations. Browser-side key encryption does not protect against malicious same-origin scripts, browser extensions with storage access or a compromised device.

No-Log Mode

No-Log Mode is enabled by default. For OpenRouter chat-completion requests, the app requests provider.zdr: true and provider.data_collection: "deny". These controls restrict routing to eligible Zero Data Retention endpoints and providers that do not non-transiently collect request data. Requests can fail when no eligible endpoint is available.

ZDR does not mean the provider never processes the prompt or prevent OpenRouter, hosting providers or network infrastructure from processing operational metadata under their own terms.

Client performance telemetry

When No-Log Mode is enabled, the browser app does not buffer or send optional performance telemetry. When disabled, the app may send allowlisted operational metrics such as timestamps, session identifier, model/mode, response length, durations and race metrics to /api/telemetry. The telemetry proxy filters nested fields before publishing, if Hugging Face publishing is configured.

Optional API-server metadata

The separate Express API records content-free operational metadata for API requests. Depending on deployment configuration, these records may be published to a Hugging Face dataset when HF_TOKEN and HF_DATASET_REPO are configured. This policy is separate from the browser app's No-Log Mode.

Opt-in research dataset

The optional API accepts contribute_to_dataset: true. When explicitly enabled, the API stores non-system messages and the final response with associated model and pipeline metadata. The current source does not implement an automatic PII scrubber for these entries. Do not submit secrets, personal data or sensitive information. If publication is configured, contributed content may become public and may be copied or redistributed.
