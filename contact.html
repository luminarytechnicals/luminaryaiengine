Contact & Support

Need help with Luminary AI Engine? Send the project team a support request, technical question or product suggestion. Luminary AI Engine is published and maintained by Luminary Technicals.

Project support contact · Updated 12 November 2026

General help and product support

For help launching the browser application, using prompt workflows, understanding settings, reporting a broken page or sharing feedback, contact the project support desk.

luminaryaiengine@luminarytechnicals.dpdns.org

Include the page URL, a concise description of the issue, the browser/device involved and steps to reproduce it. Do not email passwords, API keys, private conversations or other sensitive information.

Security vulnerability reports

Do not publish security vulnerabilities in public issues. Use the project support address with the subject [Security] Luminary AI Engine vulnerability report and include a concise description, affected component and safe reproduction details. Avoid sending live credentials or personal data.

Read the Security Policy for scope and responsible disclosure guidance.

Legal and privacy matters

For privacy, data correction or legal-policy questions, contact the organization’s legal desk at legal@luminarytechnicals.dpdns.org.

See the Privacy Policy, Terms & Conditions, Cookie Policy and Domain Policy.

Source code and issue tracking

Browse the Luminary AI Engine source repository for code, documentation and project history. Use public issue tracking for non-sensitive bugs and feature requests.
